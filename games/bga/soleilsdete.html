    Soleilsdete

    Board Game Arena 官方规则文档

    📄 BGA 官方文档

    Game goal

    Player who get the most points (Starfishes on the board) at the end of the game wins!

    Gameplay

    • Each turn, three dice are thrown. They are the same for every player.
    • Each player choose one die to select an empty slot. Die value have to be the same then slot pearl value.
    • Then write down one of the other two dice value in this slot.
    • And finally add the third die value on the left most sun on top of player board.
    • If no game end condition is reached, another turn begin.

    Suns

    After adding the sun die, if a player reach those exact values (12, 22, 32, 42, 52 or 62), he/she have a bonus. A shellfish, some points (starfish) or a bonus number (1 to 6) to add in an empty slot of his/her choice.

    Bonuses

    Pearls

    If the die value used in a slot is the same than the pearl value, the pearl is scribbled and you win 1 point (starfish).

    Carb

    If you fill a slot with a crab at the bottom, you may copy the die value on a valid adjacent top, bottom, left or right slot, even in a different zone. You then gain this new slot bonuses.

    Shellfish

    Player(s) with the most shellfishes at the end of the game wins 5 points (starfish).

    Froggy: the sun hat

    If you fill a slot with a sun hat on the top, you can choose the value you will add to sun during this turn (1 to 6, replace the sun die).


    Zones

    Player board is divided in 5 zones, each with it's own write condition rule. If there is no possible slot for a player with current dice, he/she choose witch die he/she add to Sun.

    1. Beach cabins

    Top and bottom parts of a cabin have to contain the same die value.

    2. Giants Koi

    There is no priority between Koi, but strict ascending or descending order have to be respected.

    3. Seaboats

    For each line, adjacent slots can't contain same die values.

    4. Bottles

    All values written in this zone have to be the same.

    5. Seagulls

    All values written in this zone have to be different.


    Complete a zone

    If a player write a die in every slot in a zone, he/she immediately win points (starfish) or shellfish in the banner.

    The end

    The game ends when the last sun is filled (after 20 turns) or if a player reaches or exceeds 62 suns.
