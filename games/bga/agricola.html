    农场主

    Agricola · Board Game Arena 官方规则文档

    📄 BGA 官方文档

    概述

    欢迎来到农场！在《农家乐》中，你将扮演一个农民家庭，在14轮游戏中，逐步将一个大部分为空的空间建造成充满谷物、蔬菜和动物的充满活力的农场，同时改善家庭的生活条件。玩家将他们的工人分配到行动板上的不同位置以执行各种行动来收集资源或改善农场，其中大部分资源将用于得分，但在特定时间，玩家需要支付食物以养活家庭。14轮结束后得分最高的玩家获胜！

    游戏结构

    每位玩家都可以使用各种资源，包括：

    • • 食物，用于定期喂养你的家庭
    • • 木材，用于建造围栏、马厩和许多改进设施
    • • 黏土，用于建造大多数主要改进设施
    • • 石头，用于建造其他主要改进设施
    • • 芦苇，用于一些改进设施和房屋装修
    • • 谷物和蔬菜，可以种植在你的农场
    • • 一手牌，包括7张小型改进卡和7张职业卡
    • • 工人，由小人形象表示。你在游戏开始时拥有2个工人，其余的可以在游戏过程中获得。

    每位玩家还有一个代表其农场的棋盘，其中包含：

    • • 你的家，由不同的地块表示。你的家大小以及建材会限制家庭成员数量，并在游戏结束时为你提供额外积分。
    • • 田地。可以在田地上种植谷物和蔬菜，并在收获阶段收获。
    • • 牧场及其饲养的动物。牧场由围栏隔开，里面的动物可以被烹饪成食物，或者留着获得积分。
    • • 已使用的改进或职业卡，大多数会提供各种能力、行动或得分机会，如卡上所描述。

    中央游戏板包含以下内容：

    • • 玩家可以采取的行动。请注意，每一轮将会新增一项行动，顺序较为松散。
    • • 可用的主要改进。有10张改进卡牌可以被不同玩家建造，其中大多数集中在收集或转换食物。

    游戏流程

    《农场主》（Agricola）的游戏共进行14轮。每轮开始时，某些位置会补充资源，即使它们之前已经有资源。一项新的动作会被添加到游戏板上——这些新动作通过先分为6个阶段，然后在每个阶段内随机排序，从而实现松散的随机化。然后每位玩家按顺时针顺序轮流行动，从拥有第一玩家标记的玩家开始，每位玩家通过将自己的一个家庭成员放置在特定位置上，然后立即执行该动作来进行回合。玩家还可以作为免费动作整理农场或者按各种改进描述进行特定转换。一旦完成该动作的执行，就轮到下一位玩家。玩家继续这样进行，直到所有玩家放置完所有可用的工人。在某些回合后，会进行收获阶段。然后，新的一轮开始。

    开始动作

    这些动作从游戏开始即可使用：

    • • 农场扩建：支付2个芦苇和5个你房屋当前所用材料（默认木材），以在你的家中建造一个新的房间。这个新房间必须与现有房间相连。此外，你可以在任何空地上建造马厩或牧场。这个马厩可以容纳一只动物，或者将现有牧场的容量加倍。
    • • 聚会场所：获得起始玩家标记。这意味着你将在下一轮成为第一个采取行动的玩家。这是该标记移动的唯一方式——如果某一轮没有人执行此动作，同一玩家将继续成为起始玩家。此外，你可以通过支付其上的费用从手牌中打出一张小型改良牌。
    • • 谷物种子：获得1个谷物。
    • • 农田：在你的农场中增加一块田地。此田地必须至少与另一块田地相邻（如果已有田地存在）。
    • • 课程：从你的手牌中打出一张职业卡。这类卡的第一张是免费的，但其他所有卡都需要消耗1食物。
    • • 临时工：获得2食物。
    • • 森林：回合开始时，该位置会积累3木材。获得该位置上的所有木材。
    • • 泥土坑：回合开始时，该位置会积累1粘土。获得该位置上的所有粘土。
    • • 芦苇滩：回合开始时，该位置会积累1芦苇。获得该位置上的所有芦苇。
    • • 捕鱼：回合开始时，该位置会积累1食物。获得该位置上的所有食物。

    （其他空间可能会根据玩家人数而提供。）

    第一阶段的行动

    这些行动将在第1到第4轮的某个时间添加，但它们出现的确切顺序将是随机的。

    • • 改进：支付其费用以获得1项主要或次要改进。
    • • 篱笆：支付任意数量的木材建造相同数量的篱笆，从而为动物提供牧场。必须完全围绕所有打算用作牧场的空地。
    • • 羊市场：该区域在每轮开始时积累1只羊。获得该区域上的所有羊。
    • • 粮食利用：在任意空田里播种任意数量的谷物或蔬菜。如果在田里放置谷物，立刻在同一田里再增加两份谷物；每次收获阶段，你将收获其中之一。蔬菜的方式类似，但每块田只增加一份蔬菜。此外，你��以通过将谷物转换为食物来烤面包；任何允许你这样做的卡牌都会说明通过这种方式获得多少食物。

    第二阶段的动作

    这些行动将在第5到第7轮的某个时刻添加，也会以随机顺序出现。

    • • 西部采石场：这个区域在每轮开始时积累1块石头。获得该区域的所有石头。
    • • 房屋重新开发：将木屋升级为泥屋，或将泥屋升级为石屋。为此，每间房需支付1根芦苇和1个你所升级材料的单位。必须能够升级整个房子——不能只升级单个房间。此外，完成后你可以建造一个主要或次要改进。
    • • 渴望子女：为你的家庭增加一个新工人。家庭成员数不能超过房子的房间数。该工人将在下一轮能够执行行动。

    第三阶段的行动

    这些动作将在第8轮和第9轮的某个时间点以随机顺序添加。

    • • 蔬菜种子：获得1个蔬菜。
    • • 猪市：该地点在每轮开始时累积1头猪。获得该地点上的所有猪。

    第4阶段的动作

    这些动作将在第10轮和第11轮的某个时间点以随机顺序添加。

    • • 东采石场：该地点在每轮开始时累积1块石头。获得该地点上的所有石头。
    • • 牛市：该地点在每轮开始时累积1头牛。获得该地点上的所有牛。

    第5阶段的动作

    这些动作将在第12轮和第13轮的某个时间点以随机顺序添加。

    • • 耕作：在你的农场中放置一块田地，然后像谷物利用中那样耕种任意数量的田地。
    • • 急切的生育愿望：给你的家庭增加一个新工人。其操作方式与生育愿望相同，不同之处在于不考虑房间数量的要求。

    第6阶段的行动

    此行动将在第14轮添加。

    • • 农场重建：升级你的房屋，然后建造围栏。所有关于房屋重建和围栏的规则均适用。

    收获

    在每个阶段结束后（即第4、7、9、11、13和14轮后）立即进行收获阶段。在每次收获中，以下事项按顺序发生：

    • • 农田阶段：每位玩家从每块农田中获得一份谷物或蔬菜。
    • • 饲养阶段：每位玩家为每名工人支付 2 份食物（单人游戏为 3 份，或者如果工人本轮刚添加且从未执行过动作，则只需 1 份）。玩家可以自由执行任何免费行动或交换以满足此费用。对于无法支付的每份食物，玩家将获得一张乞丐卡，游戏结束时价值 -3 分。
    • • 繁殖阶段：如果你至少拥有 2 只绵羊、猪或牛，你将获得同类型的新动物。你可以立即重新安排农场中的动物以安置这些新动物，但不能将其转换为食物。

    游戏结束

    游戏在第 14 轮及附带的收获阶段后结束。之后，玩家根据农场进行计分。

    禁用列表

    游戏选项允许你启用两个社区整理的禁用列表，从牌组中移除不平衡的卡牌。每个列表可以独立切换：

    • 竞技型（在“竞技水平”下）移除过强或破坏游戏平衡的卡牌。
    • 禁止弱牌移除过弱的卡牌。

    哪些牌被移除取决于玩家人数，因为1-2人游戏和3-4人游戏的策略差异很大。一个✓表示当该玩家人数启用禁牌列表时，该牌会被移除。1-2人列中出现的3或4表示该牌在1或2人游戏中无论如何都不可用，因为该牌只适用于3或4人游戏。

    此外，活手（Living Hand）起草模式有其自己的小型禁牌列表（见本节底部）。这些牌在活手游戏中总是会被移除，无论其他禁牌列表设置如何。
