    超级巨型幸运盒子

    Supermegaluckybox · Board Game Arena 官方规则文档

    📄 BGA 官方文档

    这是一个游戏。有盒子。你需要运气。而且它是超级超级的。

    概览

    游戏的目标是划掉你幸运盒卡上的所有数字。完成行和列以获得分数和奖励行动。每轮，将从18张牌的牌库中抽取9张数字牌。每张牌都有两个1到9的数字。对于每张抽出的牌，在你的一张幸运盒卡上划掉一个匹配的数字。4轮后，看看谁最幸运！

    游戏玩法

    游戏开始时，从5张可用的幸运盒卡中选择3张。然后揭示牌库顶部的牌。点击你任何一张幸运盒卡上的该数字来划掉它。

    当你划掉一行或一列上的所有三个数字时，获得盒子末尾显示的奖励行动。奖励有：

    • 数字：你可以在另一个盒子上划掉该数字。
    • 问号：你可以在另一个盒子上划掉任何数字。
    • 闪电符号：从供应区拿取一个或两个闪电标记。
    • 星星：用于轮次计分。
    • 月亮：用于游戏结束计分。

    闪电标记可以用来增加或减少正在玩的牌上的数字，每使用一个闪电标记可调整1。例如，如果抽到4，你可以花费一个闪电标记来划掉5或3，或者花费两个闪电标记来划掉6或2。数字9可以循环到1，反之亦然。你不能使用闪电标记来调整通过奖励行动给出的数字。

    计分

    每张已完成的幸运盒卡根据完成的轮次获得分数：

    • 第1轮 = 每张卡15分
    • 第2轮 = 每张卡12分
    • 第3轮 = 每张卡10分
    • 第4轮 = 每张卡8分

    星星根据你在一轮中获得多少来计分。

    • 1颗星星 = 1分
    • 2颗星星 = 4分
    • 3颗或更多星星 = 9分

    游戏结束时，拥有最多月亮的玩家获得6分。拥有最少月亮的玩家失去6分（双人对局除外）。如果月亮数量相同，所有平局玩家都获得或失去完整的6分。

    最后，对于未完成的幸运盒卡上的每两个划掉的盒子获得1分。

    分数最多的玩家赢得游戏！如果平局，则拥有最多月亮的玩家获胜。

    单人规则

    你可以独自举办一场派对！规则相同，除了最后的月亮计分：

    • 0个月亮 = -6 分
    • 1个月亮 = -2 分
    • 2个月亮 = 0 分
    • 3个月亮 = 1 分
    • 4个月亮 = 3 分
    • 5个月亮 = 6 分
    • 6+个月亮 = 10 分
