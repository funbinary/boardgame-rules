    Soixantedeuxsoleilsdete

    Board Game Arena 官方规则文档

    📄 BGA 官方文档

    Objective

    Have the most starfish by the end of the 20th round or once someone reaches 62 points or more in the sun row.

    Round Structure

    Three dice are rolled at the start of each round. Each player allocates the dice as follows:

    1. Choose an empty slot with a pearl corresponding to the value of one die.
    2. Write the value of another dice in the chosen spot.
    3. Add the value of the leftover dice to the previous total in the leftmost free spot in the sun row.

    If you have no valid spot to use any dice value in your general areas, you skip the steps 1 and 2 and simply choose any of the dice for step 3.

    Sun Row (Round Counter)

    Each round, you'll add your leftover dice value to the previous value in the sun row (starting from 0 in the first round). Suns are filled from left to right.

    If your new total is equal to one of the values of the left column (12, 22, 32,42,52, or 62), you get the corresponding bonus (either starfish or a bonus number)


    The bonus number can be used in an empty slot of your choice and can be chosen from any number on the die.

    Area Effects

    If you fill an entire area, you earn the shellfish listed on the side of the zone. These are added to your total at the end of the game.

    1. Beach Cabins (Pair)

    Both the top and bottom slots of a cabin must be filled with the same number

    2. Giants Koi (Sequence)

    Numbers are place on each koi respecting the < or > symbols.

    3. Seaboats (Unique)

    For each line, adjacent slots can't contain same die values.

    4. Bottles (Equal)

    All values written in this zone must be the same value.

    5. Seagulls (Non-Repeating)

    All values written in this area cannot be repeated.

    Bonuses

    Pearls

    If the die value used to fill a slot is the same as the pearl value, fill in the pearl.

    Crab

    If the filled slot has a crab at the bottom, copy the die value on a valid adjacent top, bottom, left or right slot, even in a different zone and gain that slot's bonus.

    Shell

    The player with the most shells at the end of the game gets 5 starfish.

    Frog Sun Hat

    If the filled slot has a frog hat on the top, ignore the value of the third dice and choose a value (1-6) to be added to the sun row.

    Game End

    If someone reaches a value of 62 or more in the sun row, the game ends after this round. Alternatively, the game ends after the 20th round.

    Tally your score by adding the total number of starfish earned in each area, plus the number of earned pearls, plus the number of starfish earned from sun bonuses. If you are the player with the most shells, add 5 points to your total.
