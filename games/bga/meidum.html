    Meidum

    Board Game Arena 官方规则文档

    ⭐ BGG 6.1 · 排名 #0 · 8人评分 📄 BGA 官方文档

    Overview

    Place a single pyramid block each turn until you create one of the winning formations or your opponent has no valid move. Once the blocks are placed on the game board, they are shared pieces and not owned by any players.


    Components

    16 pyramid blocks (4 colors x 4 sizes) for each player

    1 game board in center

    1 token/frame to indicate the latest pyramid block placed


    First Turn

    First Player

    Pick a size from 1 to 4

    Second Player

    Place a pyramid block (any color) with the size picked by first player, on any square


    Subsequent Turn

    - Pick a pyramid block, either with same color or same size (or both) with the latest pyramid block placed by opponent

    - Place the pyramid block on an empty square, or place on any pyramid block with a larger size (e.g. size 3 block can be placed on size 4 block, but not size 1,2,3 blocks)

    - You lose immediately if there is no valid move

    - Your opponent then takes his/her turn in the same way


    Game End

    You win immediately if after your move, either one of the following conditions is met

    - Your opponent has no valid move

    - You completed 4 in a row (orthogonally and diagonally) with pieces having all same or all different colors, only top piece counts

    - You completed a 4-level pyramid (with size 1 - 4), with pieces having all same or all different colors
