    Rangetaludotheque

    Board Game Arena 官方规则文档

    📄 BGA 官方文档

    Here’s an English version of the rules for **Range Ta Ludothèque** (“Organize Your Game Collection”).

    1. Range Ta Ludothèque — English Rules
      1. Components

    Per player:

    • 1 “Kallax” sheet (the shelf grid)
    • 1 pencil or dry erase marker

    Shared:

    • 3 six-sided dice

    ---

    1. Goal of the Game

    Organize your board game collection inside your Kallax shelf as efficiently as possible.

    After 12 rounds, the player with the most points wins.

    ---

    1. Setup

    1. Each player takes a Kallax sheet and a pencil. 2. Put the 3 dice within reach of all players. 3. Choose one scoring mode: 

      * **Classic Mode**
  * **Expert Mode** (longer and more strategic)

    ---

    1. Round Structure

    The game lasts **12 rounds**.

    Each round follows these steps:

    ---

      1. 1. Roll the Dice

    One player rolls all 3 dice in the center of the table.

    The dice results are shared by all players.

    ---

      1. 2. Assign the Dice

    Each player individually decides how to use the 3 dice:

    • One die determines the **size/shape** of the game box.
    • One die determines the **game category**.
    • One die determines the **main mechanism**.

    You may assign the dice however you want each round.

    ---

    1. Categories

    | Die Result | Category | Letter | | ---------- | ---------------- | ------ | | 1 | Puzzle Game | T | | 2 | Dexterity Game | A | | 3 | Card Game | C | | 4 | Board Game | P | | 5 | Miniatures Game | F | | 6 | Roleplaying Game | R |

    ---

    1. Mechanisms

    | Die Result | Mechanism | | ---------- | ------------ | | 1 | Bluffing | | 2 | Deduction | | 3 | Deckbuilding | | 4 | Programming | | 5 | Memory | | 6 | Secret Roles |

    ---

    1. Box Shapes

    The size die determines which polyomino shape to draw.

    • Face 1 → vertical 2-square box
    • Face 2 → horizontal 2-square box
    • Face 3 → vertical 3-square box
    • Face 4 → horizontal 3-square box
    • Face 5 → 6-square rectangle (2×3 vertical)
    • Face 6 → 6-square rectangle (3×2 horizontal)

    (See diagram on page 2 for exact layouts.)

    ---

    1. 3. Draw the Game Box

    Each player draws on their own Kallax sheet:

    1. The box shape 2. The category letter 3. The mechanism symbol

    ---

    1. Placement Rules
    • The box must fit entirely inside the Kallax.
    • Boxes may not overlap other boxes or playmats.
    • A box cannot extend outside its shelf compartment.
    • Boxes cannot “float.”

    A box must rest:

    • either on the bottom shelf,
    • or completely on top of previously drawn boxes/playmats.

    ---

    1. 4. If You Cannot Place a Box: Playmat Option

    Instead of placing a box, a player may place a **playmat**:

    • A playmat occupies exactly **1 square**.
    • It is NOT considered a game.
    • It has no category or mechanism.
    • It simply fills space and can support future boxes.

    ---

    1. 5. Next Round

    Once everyone has placed either:

    • a box,
    • or a playmat,

    start the next round:

    • reroll the dice,
    • assign the dice again,
    • draw new boxes.

    After 12 rounds, proceed to scoring.

    ---

    1. END GAME SCORING
    1. A. Classic Mode
      1. Category & Mechanism Groups

    For each category and each mechanism:

    • Find the largest orthogonally connected group
     (up/down/left/right only)
 sharing the same category or mechanism.
    • If the group contains at least 2 games:
     * score 1 point per game in that group.

    ---

      1. Empty Spaces

    Lose 1 point for every empty square (no box and no playmat).

    ---

      1. Final Classic Score

    Final score =

    • points from category groups
    • plus points from mechanism groups
    • minus empty-space penalties.

    Highest score wins.

    Tiebreaker: Fewest empty spaces.

    ---

    1. B. Expert Mode

    In Expert Mode, each game can score points from:

    1. Its category 2. Its mechanism 3. How it is stored

    ---

    1. Category Bonuses

    | Category | Bonus | | -------------- | ------------------------------------------------------------------------- | | T (Puzzle) | 1 point for each game in the compartment if none share anything in common | | A (Dexterity) | 2 points if it does NOT touch the bottom shelf | | C (Card Game) | 1 point per card game in the same compartment | | P (Board Game) | 1 point if stored horizontally | | F (Miniatures) | 1 point if the box is 6 squares large | | R (RPG) | 1 point if stored vertically |

    ---

    1. Mechanism Bonuses

    | Mechanism | Bonus | | ------------ | ---------------------------------------------------------------------- | | Bluffing | 1 point for each adjacent game sharing at least one thing in common | | Deduction | 1 point if the box is exactly 2 squares | | Deckbuilding | 1 point for each game in the same compartment that is NOT deckbuilding | | Programming | 1 point for each orthogonally adjacent programming game | | Memory | 1 point per memory game in the Kallax (max 3) | | Secret Roles | 5 points if it is the ONLY secret-role game in the Kallax |

    ---

    1. Additional Expert Scoring
    • For every completely filled compartment:
     * score 2 points per game in that compartment.
    • Still lose:
     * 1 point per empty square.

    Highest score wins. Tiebreaker: fewest empty spaces.
