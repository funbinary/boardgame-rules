    Jewelbox

    Board Game Arena 官方规则文档

    📄 BGA 官方文档

    Game Play

    Roll die. Collect and place the Beetle matching your die roll into a 4x4 grid.

    Rolling a 6 allows you to pick any of the 5 available Beetles.

    2-Player variant - 5x5 grid.

    Tools

    Tools are single use.

    Magnifying glass - choose any face-up OR face-down Beetle instead of rolling the die.

    Forceps - Swap 2 beetles tiles in your Jewel Box. Can be used before or after collecting a Beetle.

    Either - Can be used as either Magnifying Glass or Forceps.

    Limit to using 1 token per turn.

    Each unused token at the end of the game is worth 2 points.

    Scoring Guide

    Scarabs Score individually. A scarab on the edge adjacent to all different family scores 2 points. A scarab in the middle adjacent to all different family scores 3 points.
    Weevils Gain points for an unbroken horizontal or vertical line (2 = 3 points, 3 = 6 points, 4 = 10 points).

    Each weevil can only be counted once.

    Longhorns If total number of longhorns in your grid is a even number, score 2 for each longhorn. If odd number, score 1 for each longhorn.
    Ladybugs Score lady bugs which aren't adjacent to another lady bug.

    2 = 1 point, 3 = 4 points, 4 = 8 points, 5 = 15 points.

    Jewels Scores when in non-adjacent pairs, each worth 5 points. More than 2 adjacent to each other - 0 points for all.

    (Note that in the BGA implementation it seems that all weevils will "try" to be scored: an L-shaped group of 5 weevils will score 9 points (3+2) rather than 10 (4+1).)
