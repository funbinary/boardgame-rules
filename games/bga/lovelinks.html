    Lovelinks

    Board Game Arena 官方规则文档

    📄 BGA 官方文档

    Turn Summary

    1. Connect a link from your stock to a bracelets-in-assembly.

    2. If there are no valid connections, you must start a new bracelet.

    3. If a bracelet has length >= 5, it may be completed for points if key and lock match together. If you choose to do so, you must start a new bracelet.

    4. Repeat 1-3.

    Point System

    Category Action Points
    Incomplete bracelets Place link and match 1 lock and key 1
    Match 2nd lock and key in same turn 3
    Completed bracelet elements Bronze links 1
    Silver links 2
    Gold links 3
    Each link > 5 in a bracelet 2
    An opponent’s gemstones captured when completing a bracelet 1 per gemstone captured
    Domination - All gemstones are yours 10
    Links with emeralds, rubies or sapphires 5 per link
    Links with diamonds 10 per link
    Link completing bracelet Match 1 lock and key 4
    Match both locks and keys 8
    Using a link with a Master lock -4
