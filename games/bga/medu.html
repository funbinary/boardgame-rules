    Medu

    Board Game Arena 官方规则文档

    ⭐ BGG 5.5 · 排名 #27003 · 权重 1.33/5 · 83人评分 📄 BGA 官方文档

    Place a single pyramid block each turn until you create one of the winning formations or your opponent has no valid move. Once the blocks are placed on the game board, they are shared pieces and not owned by any players

    First Player: - Pick a size from 1 to 4 Second Player - Place a pyramid block (any color) with the size picked by first player, on any square

    Subsequent Turns: - Pick a pyramid block, either with same color or same size (or both) with the latest pyramid block placed by opponent - Place the pyramid block on an empty square, or place on any pyramid block with a larger size (e.g. size 2 block can be placed on size 3,4 block, but not on size 1,2 blocks) - Move the marker/frame to indicate the latest move - You lose immediately if there is no valid move - Your opponent then takes his/her turn in the same way

    Game End: You win immediately if after your move, either one of the following conditions is met - Your opponent has no valid move - You completed 4 in a row (orthogonally and diagonally) with pieces having all same or all different colors, only top piece counts - You completed a 4-level pyramid (with size 1 - 4), with pieces having all same or all different colors

    Advanced Mode: You cannot play the same piece just played by previous player, unless it is the only valid piece.
