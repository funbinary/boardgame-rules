    Fiftyfirststate

    Board Game Arena 官方规则文档

    ⭐ BGG 6.8 · 排名 #2229 · 权重 3.10/5 · 3106人评分 📄 BGA 官方文档

    Overview

    Play cards to your area in order to earn points. When a player has 25 victory points (VPs), the current round finishes and then whoever has the most VPs (including end game scoring) wins!

    Round

    The round is split into five phases, each of which is completed by every player before moving to the next, the phases are:

    1. 1. Lookout phase
    2. 2. Production phase
    3. 3. Action phase
    4. 4. Check for game end
    5. 5. Cleanup phase

    1. Lookout Phase

    First, reveal n+1 cards, where n is the number of players (e.g. 4 cards in a 3-player game). Then:

    • • Players take turns taking a new card in clockwise order.
    • • After each player has taken 1 card, discard remaining cards.

    Then draw n+1 cards again, and:

    • • Starting with the last player and proceeding counter-clockwise, each player takes a card.
    • • After each player has taken 1 card again, discard the remaining cards.

    2. Production Phase

    1. First, gain resources according to your faction board. Usually this includes 3 workers 3, 1 resource ⚙️/💳/🔫/⛽, 1 connection token >, and 1 card 🟔.
    2. Second, each deal provides the good depicted on the card.
    3. Third, each production location produces goods (including open production cards).

    3. Action Phase

    In clockwise order, each player takes a single action or passes until all players pass.

    If you pass then:

    • • you cannot take additional actions
    • • your locations cannot be razed or interacted with in any other way, e.g., use open production locations.


    The actions are:

    Construct a location

    Build a location by spending the number of grey connection tokens > equal to the card's Distance value. Earn any building bonuses and if building a production location (including open production locations), take the goods from the supply.

    Develop a location

    Build a location on top of an existing location by spending a brick and removing the old location. You earn 1 VP after developing. The new location must have at least 1 matching symbol with the old location. Ruins (and cards without icons like Radioactive Colony) can be built over with any type. Earn any building bonuses and if building a production location (including open production locations), take the goods from the supply. Any resources or tokens that were on the old card (if they were in "storage") are kept.

    Make a deal

    Spend the number of blue connection tokens > equal to the card's Distance value, and then turn the card upside down to show its Deal value. Immediately take the depicted good.

    Raze location from your hand

    Discard a card and spend the number of red connection tokens > equal to the card's Distance value. Take the goods shown in the spoils field.

    Raze opponent's location

    Spend the number of red connection tokens > equal to the location's Defense value (3 for Production, 4 for Feature, 5 for Action). Take the goods shown in the spoils field. The location's owner takes the good in the Deal field and turns the location upside down to indicate that the location is now a Ruin.

    Use an action from a location

    Spend the goods to perform the card action and keep the goods on the card to remember you used it this round, as each action can only be used once per round.

    Use an action from your faction board

    Spend the goods to perform the faction action and keep the goods on the faction board to remember you used it this round, as each action can only be used once per round.

    Use another player's open production location

    Spend a worker to earn the good on the opponent's open production location. The opponent takes a worker from the supply. You cannot send a worker to your own open production location. Each open production location can only be used once per round.

    Take a connection card

    Spend 2 workers to take a face-up connection card.

    Play a connection card

    Play a connection card and earn the goods on it.

    Place a shield token on a location (free action)

    Place a shield token on a location to increase its defense value by 1. Each location can only have 1 shield token.

    Pass

    Pass for the round and do not take any more actions.

    4. Check for Game End

    If one player has 25 VPs or more, do not go to the Cleanup Phase, and instead calculate the final score for each player.

    5. Cleanup Phase

    • • You can use the storage ability on any locations to save goods. All other goods (resources, workers, contact tokens, shields) in your personal supply and on your cards are returned to the general supply.
    • • Beside stored goods, you can only keep cards in between rounds.
    • • Discard all face-up connection cards.
    • • Pass the first player token to the left and start a new round.

    End Game Scoring

    Each player adds 1 VP per location (but 0 VP per Ruin) to their current score.

    In the case of a tie, use the following tie breakers in order:

    • • The player with the most total goods
    • • The player with the most locations
    • • If still tied, share the victory
