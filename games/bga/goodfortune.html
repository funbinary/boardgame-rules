    Good Fortune

    Overview

    Players collect matching charms to score points. Each tile has a value (shown as a die). Highest total score wins. :contentReference[oaicite:0]{index=0}

    Components

    • 21 numbered tiles (each shows 2 charms + 1 value)
    • 1 Lucky Charm Medallion (random)
    • 1 reminder tile (for tiles 1 and 21)

    Setup

    1. Randomly assign tile 1 to one player and tile 21 to another.
    2. Each player draws 8 tiles face down.
    3. Place 3 remaining tiles face up in the center → Central Line.
    4. Players reveal and sort their tiles in ascending order → Luck Line.
    5. Player with tile 1:
      • Takes the medallion
      • Starts with the small-icon side facing up

    Turn Structure

    1. Tile Selection

    • Medallion holder chooses a tile from their Luck Line.
    • Other player chooses a tile.

    2. Determine Priority

    Compare tile numbers:

    • Small icon → lower number goes first
    • Big icon → higher number goes first

    3. Place Tile

    Active player places tile at one end of Central Line:

    • If matching a charm on that end:
      • Must connect matching charm
      • If two matches possible, choose
    • If no match:
      • Place tile anyway

    4. Resolve Opposite Tile

    • If a match was made:
      • Take the tile at the opposite end
      • Add to collection (score its value)
    • If no match:
      • Remove opposite tile from game (discard)

    5. Second Player

    • Other player repeats placement + resolution

    6. End of Turn

    • Flip medallion
    • Pass it to the other player

    End of Game

    Triggered when all tiles are played.

    Scoring

    1. Group collected tiles by identical charm
    2. Order groups:
      • Most tiles first
      • Tiebreaker: highest total value
    1. Score each group:
    • (Number of tiles) × (sum of values)
    1. Total all group scores

    Winning

    Player with the highest total score wins.

    Variants

    Guessing Variant

    • Players select tiles simultaneously
    • Priority rule ignored
    • Medallion stays in center (still flipped each turn)

    Simple Variant

    • Remove medallion
    • Players alternate placing tiles
    • Tile values are ignored

    Glossary

    • Luck Line – Player’s personal row of tiles
    • Central Line – Shared row of tiles in play
    • Medallion – Determines play order
    • Collection – Tiles scored by player

    Notes / Ambiguities

    • Tile placement choice when both ends match is player-controlled.
    • Discarded tiles are permanently removed.
    • Game appears designed for 2 players only.
