    Nucleum - 简要规则

    在Nucleum中，玩家扮演19世纪萨克森地区的工业家，当时由于Nucleum（核反应堆）的发明而迎来了技术繁荣。目标是通过建造和供电城市建筑、签订合同和达成里程碑来获得最多的分数（VP）。

    游戏玩法和回合结构

    游戏是连续进行的；玩家轮流行动，没有固定的轮次或阶段。在你的回合中，你必须从以下三个选项中选择一个：

    A. 将行动板块放置到玩家版图上

    • 从你的板块池中放置一个行动板块到你的版图顶部最左边的空闲位置。
    • 以任意顺序解决板块上一个或两个行动。
    • 奖励：在这些行动之前、之间或之后，你可以完成一个合同（来自你的版图或紫色合同）。

    B. 将行动板块作为铁路使用

    • 将一个板块放置到地图上的一个空铁路位置，并放置一个你的工人在上面。
    • 颜色匹配：如果板块边缘的颜色与相邻城市或其他板块（多米诺风格）匹配，你将解决相应的行动。如果其他玩家有匹配的相邻板块，他们也可以解决行动。
    • 完成的铁路线允许运输煤炭、铀和电力。

    C. 充能

    此选项用于重置和获得资源：

    1. 收入：根据你的收入轨道标记获得泰勒、工人和分数。
    2. 放置里程碑标记：根据你当前的成就标记，在里程碑轨道上放置一个标记，以确保游戏结束时的倍数加成。
    3. Nucleum放置：如果你在一个包含Nucleum标记的段落中放置标记，将其放置到地图上的一个发电厂以获得奖励。
    4. 取回板块：将你玩家版图顶部的所有行动板块取回你的板块池。
    5. 国王日计分：当侧边版图上的一个里程碑空间被清空时触发。

    主要行动

    • 城市化（建造）：将你的游戏板上的一个城市建筑放入你的网络内的城市中，用泰勒支付费用。
    • 工业化（矿山和涡轮机）：在你的网络中放置一个矿山（生产铀）或一个涡轮机（解锁能力），用工人支付费用。建造涡轮机-矿山组合会获得特定奖励。
    • 发展：从市场购买1或2个新的行动板块添加到你的板块池中。
    • 合同：从市场获取一个银色或金色合同，并将其放置在你的游戏板上以获得即时奖励。
    • 供电：激活发电厂为连接的建筑供电。这需要煤炭（通过铁路进口）或铀（需要在发电厂中有核素）。

    重点：为布拉格供电

    • 双倍计分：在最终计分中，布拉格的已供电建筑的分数将翻倍。
    • 政府建筑：布拉格的四级建筑根据通过玩家拥有的已完成铁路线连接的特定建筑类型数量进行计分。

    四个实验（差异）

    每个玩家游戏板都有独特的技术和涡轮机效果：

    • 实验A：专注于工业和铀；为城市化提供折扣，并在建造时提供额外铀。
    • 实验B：专注于合同和里程碑；允许在任何地方工业化（忽略网络限制）并使用特殊行动板块。
    • 实验C：专注于能源效率；使用"虚拟"涡轮机和更高效的铀处理（产生3点电力而非2点）。
    • 实验D：专注于铁路；获取合同时获得成就标记，并从建造铁路线中受益。

    技术等级

    技术通过合同或里程碑解锁。

    • 等级1和2：提供永久被动奖励或即时一次性行动（例如，折扣）。
    • 等级3：强大的改变游戏规则的能力，例如忽略网络要求或增加发电厂的铀容量。
    • 等级8（最终目标）：每个实验特有的特定终局计分条件。

    游戏结束和最终计分

    当以下五个条件中有两个（在两人游戏中为三个）被满足时，游戏结束：

    1. 行动板块牌库已空。
    2. 某个玩家的所有三个里程碑空间都已空。
    3. 某个玩家已解锁全部8项技术。
    4. 某个玩家达到70分。
    5. 最后一块合同板块被抽走。

    最终计分：

    • 里程碑：根据里程碑板块的条件和其等级的倍数，为轨道上的标记计算分数。位于"0"位置的标记价值3分。
    • 建筑：所有通电建筑背面显示的分数（在布拉格翻倍）。
    • 收入轨道：如果标记到达各轨道的最终位置，获得3、6或10分。
    • 第八科技：计分个人终极目标。

    2. 格尔利茨
    3. 玛丽恩堡
    4. 里萨

    橙色城市：

    1. 开姆尼茨
    2. 德累斯顿
    3. 弗赖贝格
    4. 约阿希姆斯塔尔

    白色城市：

    1. 奥西希
    2. 格拉胡蒂
    3. 莱比锡
    4. 普劳恩

    当以下五个条件中的两个（双人游戏中为三个）被满足时，游戏结束：

    1. 行动板块牌库已空。
    2. 白银和黄金合约牌库已空。
    3. 所有玩家至少充能了3次（里程碑位置上没有里程碑标记）
    4. 至少一名玩家解锁了全部8项科技。
    5. 至少一名玩家达到70分
