    Gatsby

    Board Game Arena 官方规则文档

    ⭐ BGG 6.7 · 排名 #5625 · 权重 2.00/5 · 675人评分 📄 BGA 官方文档

    Objective

    Win by either:

    • Collecting 3 characters of the same suit, OR

    • Collecting 1 character from each of the 5 suits

    If no one achieves a victory condition, the player with the most Prestige points from characters and special actions wins.

    Turn Overview

    Players alternate turns. On your turn:

    • Place the Action token on a different action space (you can't repeat the last action).

    • Perform the listed actions in the specified order.

    • At the end of the turn, check if you've rallied any characters.

    If a victory condition is met, the game ends immediately.

    Victory Conditions

    Game ends immediately if:

    • You have 3 characters of the same suit

    • You have 1 character from each of the 5 suits

    Otherwise, the game ends immediately when the last character of any location is rallied.

    End Game Scoring

    Add up Prestige points on all your characters

    +1 for an unused Special Action tile on your board

    +1 per discarded Special Action tile during the game

    If tied, whoever has the most characters wins. If still tied, play again.

    Location Rules

    Cabaret

    Place Influence tokens to form a continuous orthogonal path from one edge to the other.

    You may also rally a character by occupying all 4 matching circle spaces.

    Tokens must always be placed orthogonally adjacent to another token (any color).

    Finance Center

    Advance your Ascension token upward.

    If you reach or pass a character, you rally it.

    If you're behind your opponent → move 2 spaces

    If tied/ahead → move 1 space

    Racetrack

    Place tokens from left to right on available tracks.

    When a track fills, the player with the majority takes the character.

    Return tokens; that track is now closed (overlay tile).

    Action Options

    Each main action specifies what to do and in what order:

    Place Influence in Cabaret (1 or 2 tokens)

    Advance in Finance and/or place in Racetrack

    Each turn must use a new action space

    Special Actions

    Unique, powerful one-time actions

    Placed on your player board, replacing any existing special

    Examples include:

    • Place 3 tokens at Cabaret

    • Swap Influence tokens with opponent

    • Advance in Finance and place in Racetrack

    • Draw multiple Special Action tiles and choose one

    Bonuses

    Some spaces grant bonuses when you land on or cover them

    Bonuses include:

    • Swap characters

    • Extra placement

    • Influence swap

    • Advance Ascension

    • Restrict opponent's next action.
