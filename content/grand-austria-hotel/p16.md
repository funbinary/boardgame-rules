## 符号说明

〔左栏符号表,图内文字照录〕

| 图内文字 | 说明 |
| --- | --- |
| +2 | 推进皇帝计分轨对应数字的格数。 |
| +2 | 拿取对应颜色和数量餐点或饮料。把它放到一个房客的需求区域或你的厨房里。 |
| +1 | 拿取任意颜色、对应数量的餐点或饮料。把它放到一个房客的需求区域或你的厨房里。 |
| 2 | 你获得对应的分数。 |
| + 1x | 根据放置的规则,准备对应数量的你所选择的客房。你必须支付费用。 |
| + -1 | 根据放置的规则,准备对应数量的你所选择的客房。你必须支付少 1 元的费用。 |
| + 0 | 根据放置的规则,准备对应数量的你所选择的客房。你无须支付费用。 |
| +1 | 你获得对应数量的钱。 |
| 0 ↓ | 你可以免费打出1张员工卡。 |

〔右栏符号表,图内文字照录〕

| 图内文字 | 说明 |
| --- | --- |
| -3 ↓ | 你可以少支付3元打出一张员工卡。 |
| +1 | 从牌库顶摸对应数量的员工卡,加入手牌中。 |
| 3 ↓↓ | 从牌库顶摸 3 张员工卡并立刻打出其中 1 张,你可以少支付 3 元。把另外 2 张放回到牌库底。 |
| — | 你可以把指定数量、指定颜色的客房翻到背面,以显示这个(些)客房已被入住。灰色代表你可以翻任何一种颜色的客房。 |
| 1x | 完成1张特定颜色的房客卡的需求。从一般供应区拿取所需的餐点和饮料,把它们放到该张房客卡上。灰色代表你可以完成任何颜色的房客需求。 |
| 0 | 准备1个指定颜色的客房,不需支付费用。 |
| + 0 | 从游戏图板上拿取一张正面朝上的房客卡并把它放到你的咖啡厅,无须支付费用。 |
