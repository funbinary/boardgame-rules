### 契约劳工

当玩家派遣罢工时,劳资双方将达成效力至少维持一轮的劳动契约(新派遣至企业的劳工提供劳动力,企业的经营者则给予薪资作为回报)。为了表明双方的关系,每当劳工被派遣到企业时,将劳工平放躺在栏位上,代表他们是签署劳动契约的契约劳工。契约劳工在劳动契约期间,不能被派遣至其他企业,企业经营者不能调降薪资、也不能出售企业。于生产阶段,劳工生产资源之后,将立即回复成立姿(解除劳动契约)。

### 派遣劳工至工会

除了图板上的企业所提供的栏位之外,玩家也能将自己的熟练劳工派遣到工会(位于自己的玩家图板),但必须遵守下述额外规则:

将 **1 名**劳工派遣至工会之前,玩家必须有至少 **4 名**其他劳工在该产业的企业工作。

须注意的是,派遣至工会的劳工被视为就业、而且是签署终身劳动契约的劳工。换言之,玩家不能将工会的劳工改派至他处。然而于游戏过程中,只要玩家于该工会产业工作的劳工少于 **4 名**,就必须立即将对应工会的劳工移至职业介绍所。

每个工会所提供的增益为:于生产阶段提供 **1 影响力**,于得分阶段提供 **2 胜利分数**。请留意,工会的劳工虽然视为就业劳工,但不会获得薪资。

> 范例:**吉姆**想在农业产业筹组工会。当下他只有 2 名劳工在资本阶级经营的农业企业工作,而场上还有 2 间中产阶级经营的企业能派遣劳工。由于他有 3 名待业劳工,其中 1 名还是农业专长,因此他先执行派遣劳工的行动,将 2 名无经验劳工派往 2 间中产阶级企业,使自己拥有 4 名在农业产业工作的劳工,而符合筹组工会的条件。接着,他再以第三次派遣机会将绿色劳工放在自己图板对应的工会栏位。
>
> *[图:玩家图板的"工会"栏位——绿、蓝、红、橙、紫五个产业栏位,各放置劳工]*

> 之后,**克莱儿**(中产阶级)决定出售她的企业,而将**吉姆**的劳工移至职业介绍所。**吉姆**现在只剩 3 名在农业产业工作的劳工,代表他不再符合筹组农业工会的门槛,而必须将工会的绿色劳工移回职业介绍所。

### 购买货物与服务

玩家能以此行动购买为了满足基本需求而需要的货物与服务。

购买货物与服务时,选择 **1 种**货物或服务(食物、奢侈品、医疗、教育或影响力),并从至多 **2 位**卖家购买资源。玩家能向每位卖家购买数量至多等同自己当前人口数的指示物。假设玩家当前的人口数为 4,能向资本阶级与国外市场分别购买 4 个奢侈品,或是向国家与中产阶级分别购买 4 个医疗。

须留意的是,不是每位卖家都提供玩家需要的货物与服务,即使有,数量也未必符合需求。下表为每位卖家可能贩售的资源。

|          | 食物 | 奢侈品 | 医疗 | 教育 | 影响力 |
| -------- | :-: | :-: | :-: | :-: | :-: |
| 资本阶级  | ✓ | ✓ | ✓ | ✓ | ✗ |
| 中产阶级  | ✓ | ✓ | ✓ | ✓ | ✗ |
| 国外市场  | ✓ | ✓ | ✗ | ✗ | ✗ |
| 国家     | * | * | ✓ | ✓ | ✓ |

\* 仅于特定情形提供货物

每种货物或服务的贩售价格标示在卖家处。资本阶级与中产阶级的贩售价格列在各自的玩家图板上(而且他们能在自己的回合以自由行动改变价格);国外市场的贩售价格列在主游戏图板的进口区底部,这些售价会受到对外贸易政策(政策 6)的影响,而可能必须向国家支付额外的关税;国家的贩售价格由其国家福利:医疗与补助(政策 4)、国家福利:教育(政策 5)决定。若国家获得生产货物(食物或奢侈品)的企业,这些货物的贩售价格则列在国家的玩家图板上(固定价格)。此外,国家的影响力售价也是固定价格并且列在图板上。

购买资源之后,将资源放在自己玩家图板的货物与服务区。

> 范例:**吉姆**想再购买一些医疗,而他的人口数为 5,因此能向每位卖家分别购买至多 5 个医疗指示物。公共服务部门提供 6 个医疗指示物,每个售价 5¥,因此他花费 25¥ 购买其中 5 个。资本阶级也以 8¥ 的价格提供医疗,虽然**吉姆**也能向资本阶级购买至多 5 个医疗指示物,但资本阶级只有 3 个指示物,因此**吉姆**最后再花费 24¥ 购买 3 个指示物。
>
> 之后,当**吉姆**的人口数变为 6 时,他想从国外市场购买奢侈品。虽然奢侈品在国外市场的售价为 6¥,但由于当前对外贸易政策为意识形态 B,代表每个奢侈品必须花费额外 3¥ 作为关税。因此**吉姆**购买货物除了花费 36¥ 之外(将这些费用放回供应区),还向国家了支付 18¥ 的关税。
