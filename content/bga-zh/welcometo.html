在你的三条私人街道上建造房屋。玩家共享相同的房屋编号和行动选择，但会追求各自的策略。通过获得最高分数来展示你的策略是最好的。

设置

每位玩家都有自己的游戏表。表的上半部分包含三条街道，每条街道被划分为多个房屋。表的下半部分用于计分。

你的游戏表仅供你自己使用。玩家绝对不要在其他玩家的表上书写。

每局游戏中，有3个共享的城市规划，编号为no.1（蓝色）、no.2（黄色）和no.3（红色）。这些是玩家可以竞争分数的目标。

此外，还有一叠81张建筑卡。每张建筑卡正面有一个数字（1-15），背面有一个效果（6种可能的效果之一）。某些数字和效果比其他更常见；完整表格请参见#建筑卡分解。

游戏概览

以下描述基础游戏。游戏变体请参见#变体，这些变体可能会改变游戏的某些方面。

游戏分为多个回合。每回合，所有玩家同时进行游戏。游戏持续进行，直到有玩家触发游戏结束。

每回合遵循以下步骤：

  1. 1. 新的建筑卡被翻开。将有3个数字/效果组合。
  2. 2. 选择一个数字/效果组合，并将该数字写入你的一处空房屋中。
  3. 3. 可选地，使用你选择的组合上的效果。
  4. 4. 你可以完成任何城市规划。
  5. 5. 所有玩家的选择被公开。检查游戏是否结束。

1. 新的建筑卡被翻开

建筑卡被分为3叠，每叠27张，初始状态显示数字面。每回合，顶部的卡片被翻过来，将其变为效果面，同时露出下一个数字面。

注意：每张卡片的数字面在角落也显示了其效果面。由于卡片的翻转方式，这意味着角落的效果正是你下回合将看到的效果。

如果牌库用完，每叠弃牌堆的顶卡（显示效果面）被保留，其余所有卡片被重新洗牌组成新的牌堆。

2. 选择一个数字/效果组合并写入其数字

选择三个可用的数字/效果对中的一个。然后选择一个你的空房屋，并将数字写入该房屋。

你的房屋数字必须遵循这个规则：街道上的房屋数字必须从左到右严格递增。不允许重复。但是，允许有空缺，包括无法用数字填满的空缺。此外，数字不必连续；例如，在7的右边放一个10是合法的。

你必须写入数字。选择数字/效果对后不写入数字是不合法的。

如果任何数字/效果对中的数字都可以写入，你必须选择一个数字/效果对。如果无法选择，你将不得不接受一次许可拒绝。（请参阅下方的#许可拒绝。）

3. 可选地，使用效果

你可以选择使用你选择的数字/效果对的效果。效果总是可选的；如果你不想，不必使用效果。

请参阅#效果获取所有效果的列表。

4. 你可以完成任何城市规划

如果你满足城市规划的条件，你可以选择完成它。完成城市规划总是可选的；如果你愿意，可以选择推迟到以后的回合完成。

每个城市规划都有两个分值。第一个完成特定城市规划的玩家获得较高分值。如果多个玩家在同一回合完成该城市规划，所有玩家都获得较高分值。之后，任何其他完成该城市规划的玩家将获得较低分值。（在BGA上，城市规划显示在侧边栏每个玩家下方。如果玩家首先完成一个城市规划，该城市规划会显示"1"。如果他们稍后完成该城市规划，会显示"2"。）

如果你完成了一个城市规划，并且这是任何玩家第一次完成城市规划，你还可以选择是否重新洗牌建造卡。如果你选择重新洗牌，所有建造卡会被收集在一起并重新洗成3个新牌堆。（这也导致下一回合的效果完全不可预测。）

这个选项只在任何玩家第一次完成城市规划时可用；之后没有重新洗牌选项。如果多个玩家同时完成城市规划，只要有一个玩家选择重新洗牌，卡牌就会被重新洗牌。

请参阅#城市规划获取更多关于城市规划的规则。

玩家完成全部3个城市规划是游戏结束的触发条件之一。

5. 检查游戏是否结束

上述步骤2-4都是同时进行的，且每个玩家不知道其他玩家在做什么。一旦所有玩家完成回合，每个玩家所做的一切都会被揭示。（在BGA上，有一个动画显示哪些房子被哪些玩家填满。此外，你可以点击每个玩家查看他们的游戏表。）

当任何玩家满足任何以下游戏结束条件时，游戏结束：

  • • 他们有3次许可证拒绝。
  • • 他们完成了所有3个城市规划。
  • • 他们填满了游戏表上的所有房子。

如果游戏尚未结束，将按照相同步骤开始新回合。

当游戏结束时，计算每个玩家的分数；分数最高的玩家获胜。有关详细信息，请参阅#计分。

许可证拒绝

如果你无法完成回合的步骤2（填写数字），你必须进行许可证拒绝。在你的许可证拒绝区域划掉最小的未划掉的数字，并跳过回合的步骤2-3。（你可以在游戏表下半部分的最右侧列找到许可证拒绝区域；它是两条轨道中的下一条。）

你仍然可以执行步骤4（完成城市规划）。你也将与其他玩家一起执行步骤5（揭示并检查游戏结束）。

拥有3次许可证拒绝是游戏结束的触发条件之一。

效果

有6种效果。请记住，所有效果都是可选的。

测量员（白色栅栏）

测量员允许你在两栋房子之间画一条栅栏。这会将你的房子划分为不同大小的庄园。

当你使用测量员效果时，在两栋房子之间画一条栅栏，如果它们尚未被线条连接（见下文）且它们的数字不同（见下面的"bis"效果）。无论你在哪里填写房子数字，你都可以画任何合法的栅栏。（每条街道的最左端和最右端也有免费栅栏。）

完成的庄园是指一条街道上的一系列完全编号的房子（无间隙），左右两侧都有栅栏。

庄园最多只能有6栋房子。超过6栋房子的系列不是庄园，必须分割。另一方面，即使庄园已经有6栋房子（或更少），它仍然可以进一步分割。

庄园通常用于完成城市规划。如果有些房子用于完成城市规划，房子上方会画一条水平线。测量员不能用于在由水平线连接的两栋房子之间画栅栏。

特工（紫色箭头）

特工允许你提高所有特定规模的庄园的价值。

在你的计分表上，特工区域包含6条轨道，对应规模1-6的庄园。当你使用特工效果时，划掉任意一条轨道上的一个数字。在每条轨道上，你必须从上到下划掉数字。（每条轨道最底部的数字不能被划掉。）

特定规模的庄园的价值等于其轨道上最上方（最小）未被划掉的数字。

景观设计师（绿色树木）

景观设计师允许你在街道上建造公园。

每条街道有几个公园，标记在街道最右侧的圆圈中。当你使用景观设计师效果时，查看你写下房屋编号的街道。划掉该街道最左侧的公园圆圈。（最右侧的数字不在圆圈内，不能被划掉。）游戏结束时，你将从每条街道中获取最左侧未被划掉的数字作为分数。

请注意，如果你成功划掉了一条街道上的所有公园圆圈，分数会有显著提升。如果一条街道上的所有公园圆圈都被划掉，对该街道的进一步景观设计师效果将无效；你不能从其他街道划掉公园。

泳池制造商（蓝色泳池）

泳池制造商允许你为某些可以支持泳池的房屋建造泳池。

一些房屋上方有泳池。当你使用泳池制造商效果时，查看你写下房屋编号的房屋。如果有泳池，圈出泳池并划掉你泳池计分中最小的数字（位于你计分表的下半部分）。游戏结束时，你将从你的泳池计分中获取最小的未被划掉的数字作为分数。

你可以在没有泳池的房屋上使用泳池效果，但这样不会产生任何效果。你可以在有泳池的房屋上写下数字，即使其效果不是泳池，但这意味着泳池永远不会被圈出。

临时工机构（橙色建筑）

临时工机构修改你正在书写的房屋编号。与所有其他效果不同，临时工机构在你书写房屋编号时应用（第2步）。

当你选择带有临时工机构效果的数字/效果组合时，你可以在房屋编号上加上或减去1或2。例如，如果你选择数字12，你可以写下10-14的房屋编号。

房屋编号可以低至0（不允许写-1），高至17。

此外，在你的临时机构区域（位于你的游戏表下半部分）划掉一个空格。游戏结束时，玩家会根据他们使用临时机构的频率获得奖励分数。

特殊情况：请记住，如果可能的话，你必须从数字/效果对中写一个数字，但使用行动总是可选的。如果有一个包含临时机构效果的数字/效果对，你通常无法写下该数字，但你可以通过使用临时机构来写下该数字，在这种情况下，如果你更愿意接受许可拒绝，可以选择不使用临时机构。

Bis（红色邮箱）

Bis允许你在同一条街道上写下重复的数字。

当你使用bis效果时，选择一个与你已编号房屋相邻且中间没有栅栏的房屋。写下相同的数字，后跟一个"b"。（如果一个房屋与两个已编号房屋相邻，你可以选择复制哪个数字。） 为了递增规则的目的，由bis创建的重复数字仍被视为按递增顺序排列。 重复的房屋永远不能被栅栏分隔。这意味着，当你将数字复制到相邻房屋时，它们之间不能有栅栏；将来，你也不能在这两个房屋之间画栅栏。 此外，在你的bis惩罚（位于你的游戏表下半部分）中划掉最小的数字。游戏结束时，你将失去等于你bis惩罚中最小未划掉数字的分数。 请记住，效果是可选的。如果你不想，就不必使用bis效果，只有当你决定使用bis效果时才需要承担bis惩罚。

城市规划

游戏开始时，有3个城市规划。所有玩家竞争相同的城市规划，它们在游戏过程中不会被移除或替换。

标准游戏中的所有城市规划都要求你拥有特定规模的庄园。要完成这样的城市规划，你必须拥有游戏表上所需的庄园。此外，不同城市规划之间不能重复使用房屋。为了表示这一点，已用于城市规划的庄园将在其房屋上方画一条水平线。 当你选择完成这样的城市规划时，在每个使用的庄园的所有房屋上方画一条水平线。 庄园可以出现在你的游戏街道的任何位置。没有规定它们必须出现在哪些街道上。

游戏的变体可能会使用不涉及 estates 的城市计划。一般来说，如果城市计划涉及房屋，那么这些房屋就被"使用完"了，不能用于其他与房屋/estate 相关的城市计划。如果城市计划涉及房屋可能拥有的其他东西（水池、bis 数字等），则房屋不会被"使用完"。有关游戏变体的更多信息，请参见 #Variants。

每个城市计划都有两个分数值。首先完成特定城市计划的玩家获得较高的分数。如果多个玩家在同一回合内完成该城市计划，他们都获得较高的分数。此后，任何其他完成该城市计划的玩家将获得较低的分数。（在 BGA 上，城市计划显示在侧边栏每个玩家的下方。如果玩家首先完成一个城市计划，该城市计划会标记为"1"。如果他们稍后完成一个城市计划，该城市计划会标记为"2"。）

如果你完成了一个城市计划，并且这是任何玩家第一次完成城市计划，你可以选择是否重新洗牌建造牌。如果你选择重新洗牌，所有建造牌会被收集在一起并重新洗成 3 个新牌堆。（这也导致下一回合的效果完全不可预测。）

这个选项只在任何玩家第一次完成城市计划时可用；之后没有重新洗牌的选项。如果多个玩家同时完成城市计划，只要其中任何一位玩家选择重新洗牌，牌就会被重新洗牌。

计分

游戏结束时，你的分数根据以下内容计算。（这些内容与你的游戏表下半部分从左到右出现的顺序相同。）

  • • 城市规划：每完成一个城市规划，你将获得分数。如果你是第一个完成该城市规划的玩家，你将获得其高分值。如果你稍后完成该城市规划，你将获得其低分值。如果你完全没有完成该城市规划，你将不得分。
  • • 公园：对于每条街道，你将根据其公园获得最小的未划掉数字的分数。
  • • 游泳池：你将在你的游泳池计分区域获得最小的未划掉数字的分数（基于你圈出的游泳池数量）。
  • • 临时机构：在临时机构区域拥有最多已划格数的所有玩家各得7分。拥有第二多已划格数的所有玩家各得4分，拥有第三多已划格数的所有玩家各得1分。
  • • 房地产：每完成一个房地产，你将获得分数。每个特定大小的房地产的价值是其轨道上最小的未划掉数字。（记住，房地产必须完全编号才能计分，而且房地产最多只能有6栋房子。）
  • • 双倍：你将失去等于你的双倍罚分区域中最小的未划掉数字的分数（基于你使用的双倍效果数量）。
  • • 环岛：这个罚分在基础游戏中不存在。在进变体中，你将失去等于你建造的环岛数量对应的最小未划掉数字的分数。
  • • 许可拒绝：你将失去等于你获得的许可拒绝数量对应的最小未划掉数字的分数。

分数最高的玩家获胜。如果平局，则完成最多房地产的玩家获胜。如果仍然平局，则完成最多1号房地产的玩家获胜，然后是2号，3号，以此类推。

变体

以下变体可以在游戏开始前选择。在一局游戏中只能选择一种"棋盘"变体，但其他所有变体都可以相互兼容。

  • • 进变体
  • • 专家规则
  • • 棋盘：冰淇淋车
  • • 棋盘：圣诞彩灯
  • • 棋盘：复活节彩蛋

进变体有额外的1号和2号城市规划。它们与其他城市规划一起洗牌，可能会也可能不会出现在游戏中。

每个棋盘都有额外的3号城市规划。它们替换基础游戏中的3号城市规划，因此其中一个总是会出现在游戏中。

进变体

在进变体中，你可以获得一个额外行动：建造环岛。如果你想建造环岛，你需要在你的回合的第2步（选择数字/效果对）之前进行。

要建造一个环岛，选择一个空房子。该房子会变成环岛，用一个带点的圆圈表示。此外，在环岛惩罚区域中划掉最小的未划圈数字。游戏结束时，你将失去等于环岛惩罚区域中最小的未划圈数字的分数。

环岛将其街道分成两部分。每部分必须单独具有严格递增的数字，但编号在环岛处重置；左侧部分不必小于右侧部分。

在整个游戏中，你最多只能建造2个环岛（在环岛惩罚区域中用2个圆圈表示），并且每个回合只能建造1个环岛。即使之后无法写数字，你也可以建造环岛。建造环岛总是可选的；但是，如果你建造了环岛，你可能会变得能够（或无法）写数字/效果对，并必须相应地执行你的回合（或拒绝许可）。

环岛还带有左右两侧的栅栏，类似于街道的最左侧和最右侧有栅栏。这可能会产生庄园。环岛永远不是房子，也不计入任何引用房子（或大小为1的庄园）的内容。

高级城市规划

在高级变体游戏中，城市规划1号和2号可以使用高级城市规划。一些注意事项：

  • • 所有2号高级城市规划都涉及池塘和公园。这些不涉及房子，因此不消耗房子。一个房子的池塘可以用于一个这样的城市规划，该房子仍可用于另一个城市规划。
  • • 两个1号高级城市规划要求在特定街道上建造所有房子。这些确实消耗房子，其庄园不能进一步分割。（注意庄园最多只能包含6个房子。）街道上的环岛是允许的，并计入城市规划。
  • • 一个1号高级城市规划要求在所有街道上建造最左侧和最右侧的房子。这些确实消耗房子。与所有其他城市规划不同，这个城市规划单独标记房子。包含这样一个标记房子的庄园不能用于城市规划，但标记的房子可以用栅栏分开，剩余的庄园仍可用于另一个城市规划。

专家规则

在专家规则中，选择数字/效果对的规则完全改变。每个玩家有自己的卡片可供选择。

游戏开始时，每个玩家发到3张建筑卡。对于第2步（选择数字/效果对），你选择一张卡用于其数字面，另一张卡用于其效果面。

在第5步（揭示并检查游戏结束）中，你还要将你的第三张牌传给下一位玩家。这会导致你从前一位玩家那里获得一张牌。你摸两张新牌，这样你就有3张牌可以在下一个回合中选择。

当牌库被重新洗牌时会发生什么还不清楚，但似乎玩家手牌中剩余的牌会保留，不会被重新洗牌。

专家规则没有自己的城市计划，它们只是修改规则来选择一个数字/效果组合。它们还为游戏引入了不对称性，因为玩家拥有自己的牌。

板块：冰淇淋车

板块上有一些冰淇淋车，现在房屋可能会要求冰淇淋（由每个房屋旁的冰淇淋表示，有1或2个球）。

每条街道都有一个冰淇淋车，从街道的左侧或右侧开始。对于底部的街道，你可以在你在该街道上写下第一个数字时选择冰淇淋车的起始位置。卡车只会沿着街道一个方向移动，永远不会后退。

当你在街道上写一个数字时，它的卡车可以沿着街道移动。如果你的数字比卡车更靠前，卡车会移动直到停在你标记的房屋上。（移动是通过在房屋下方画一条线来表示的。）如果该房屋有冰淇淋，圈出冰淇淋。此外，卡车会跳过中间的任何房屋；划掉这些房屋上的任何冰淇淋。

如果你圈出或划掉一条街道上的最后一个冰淇淋，该街道上的卡车就完成了它的行程。如果你是这条街道上第一个这样做的玩家，圈出街道末尾的奖励。（就像城市计划一样，如果多个玩家在同一回合这样做，他们都获得奖励。）所有其他玩家划掉奖励，这意味着他们不能再获得这条街道的奖励。然而，他们各自的卡车仍然可以继续行程，其他街道上的卡车不受影响。对于底部的街道，只有一个奖励可供所有玩家获得，即使他们选择以不同方向移动他们的卡车。

环岛不是房屋。放置环岛不会移动卡车，环岛上的冰淇淋永远无法收集。

计分

你可以按以下方式获得额外分数：

  • • 冰淇淋球：每个被圈出的冰淇淋得1分。注意，一些冰淇淋有1个球，而其他有2个球。
  • • 卡车奖励：如果你在一条街道上获得卡车奖励，该街道上每个被圈出的冰淇淋（不是球）得1分。

城市计划

  • • 两个方案需要 estates（区域）拥有（或不拥有）冰淇淋筒。这些仅指该区域房屋中的冰淇淋球。它们计算的是冰淇淋筒，而不是冰淇淋球。记住，如果卡车停在该房屋上，收集冰淇淋是强制性的。
  • • 一个方案需要街道上的所有冰淇淋筒。由于它不涉及房屋，其房屋可用于另一个城市方案。

板块：圣诞灯

您可以在房屋下方绘制圣诞灯。

每当两个房屋号码是连续的（差值最多为1）或相等（使用此效果），它们就会用圣诞灯连接在一起。（这用房屋下方的曲线表示，连接这些房屋。）

一串圣诞灯是一系列房屋，所有房屋都通过这种方式连接到下一个房屋。一串灯必须至少包含2个房屋；如果没有连接，就没有串。

环岛不是数字。它们总是会打断一串灯。

计分

您可以按以下方式获得额外分数：

  • • 圣诞灯：对于每条街道，您获得分数等于该街道上最长的圣诞灯串，计算由它连接的房屋数量。如果您有多个串，只计算最长的那个；如果您有多个最长串，计算其中一个。

城市方案

  • • 一个方案需要 estates（区域），每个区域都有用圣诞灯连接的房屋。对于每个区域，其所有房屋必须属于同一个串。这两个区域本身可以连接也可以不连接。
  • • 一个方案需要 estates（区域），每个区域的房屋不用圣诞灯连接。请注意，如果房屋号码合适，绘制圣诞灯是强制性的。区域两端的房屋可以在区域外连接。
  • • 一个方案需要街道上的所有房屋连接在一个串中。由于它不涉及房屋，其房屋可用于另一个城市方案。环岛不计入；街道上的环岛会导致该街道无法完成此城市方案，即使环岛位于街道的末端。

板块：复活节彩蛋

一些房屋上有1或2个彩蛋。您必须使用您的房屋号码圈出这些彩蛋。

当您在房屋上写一个数字时，它的"洞"可以圈出该房屋上的彩蛋。写一个不圈彩蛋（或圈住的彩蛋少于实际数量）的数字是合法的，但在这种情况下，该房屋上未被圈住的彩蛋将丢失。

环岛不是数字。它们不能收集蛋。

计分

您将获得额外分数，如下所示：

  • • 复活节蛋：计算您收集的蛋的数量。收集至少6/10/14/18个蛋可获得5/10/20/35分。（只计算最高分。）

城市规划

  • • 两个规划要求庄园有（或没有）蛋。这些仅指该庄园房屋中的蛋。记住，如果数字合适，收集蛋是强制性的。
  • • 一个规划要求街道上的所有蛋。由于它不涉及房屋，这些房屋可以用于另一个城市规划。
