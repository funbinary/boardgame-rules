❓ 常见问题

什么是「桌游规则书」？
「桌游规则书」（rule.zhibinai.cn）是一个免费的中文桌游规则查询网站，收录 37 款热门桌游的完整中文规则书全文，以及 Board Game Arena 平台 1600+ 款游戏的官方规则文档中文版，支持手机浏览，无需注册。
网站收录了哪些桌游的中文规则书？
目前收录 37 款完整中文规则书，包括：七大奇迹、工业革命：伯明翰、展翅翱翔、农场主、波多黎各、卡坦岛、永恒之谷、沙丘：帝国、马拉开波、方舟动物园、阿勒农场、奥地利大饭店、电力公司等，均为规则书全文转录（多数含扩展），而非缩写摘要；另有 Board Game Arena 全部 1600+ 款游戏的规则文档中文版。

中文规则书整理自官方中文规则书扫描件与公开转录文本，每个页面均注明原始出处与版权归属；Board Game Arena 规则译自其官方英文文档 Wiki。全部内容仅供个人学习查阅，版权归原作者所有。
