# 用户模块 + 游戏收藏（Go 后端）

在 zhibinai.cn 增加用户系统：注册/登录后可在**任意游戏页**（精选 20 页 + BGA 1632 页）一键标记 **已有 / 想买 / 想玩**，并有「我的收藏」页集中管理。后端用 Go 全新实现，与站点同域反代，SQLite 存储。

## 已定决策（提问未答，按推荐默认）
- 登录方式：**用户名 + 密码**（bcrypt 哈希）
- 注册：**开放注册** + 接口限流防滥用
- 收藏：**仅自己可见**（表结构预留 sharing 扩展位）
- 数据库：**SQLite**（`modernc.org/sqlite` 纯 Go 驱动，`CGO_ENABLED=0` 可交叉编译，单文件零运维）
- Web 框架：**不引框架**，Go 1.22 标准库 `net/http`（方法+通配路由）；依赖仅 bcrypt + sqlite 两个

## 一、后端（新目录 `server/`）

```
server/
  go.mod                        # module github.com/funbinary/boardgame-rules/server
  cmd/rules-api/main.go         # 入口：env 配置、路由、优雅退出
  internal/store/               # SQLite 打开/迁移 + users/sessions/collections
  internal/auth/                # bcrypt、会话 token（随机32B，库存 sha256，30天滑动过期）
  internal/api/                 # handlers、JSON 错误、限流、security headers
  internal/static/              # 静态托管（仅本地开发用 SERVE_STATIC 开启）
  deploy/rules-api.service      # systemd 单元
  deploy/bootstrap.sh           # 服务器一次性引导脚本
  server_test.go…               # httptest + 临时库单测
```

**表结构**：`users(id, username UNIQUE COLLATE NOCASE, pw_hash, created_at)`；`sessions(token_hash PK, user_id, expires_at)`；`collections(user_id, game_key, status, name, en, updated_at, PK(user_id,game_key))`，status ∈ `owned|wishlist|play`（已有/想买/想玩）。

**API**（前缀 `/api`，Cookie `rules_session`：HttpOnly+Secure+SameSite=Lax）：
- `POST /api/register|login|logout`、`GET /api/me`、`GET /api/health`
- `GET /api/collection` → 三张清单
- `PUT /api/collection/{game_key}` body `{status, name, en}`：设置/移动/移除（status 为空即移除）
- `game_key` 规范：精选页 slug（`seti`）或 `bga/<id>`（`bga/catan`），由前端从 pathname 推导，服务端正则校验 + name 快照限长 60 字
- 限流（内存桶）：注册 5/时/IP，登录失败 10 次/15 分/用户名 + 15/5 分/IP；收藏写 60/分/IP

## 二、前端（延续现有零构建风格，手写 vanilla JS）

- **`assets/js/account.js`（新增，全站引用）**：`GET /api/me` 后在 topbar 注入「🔐 登录」或「👤 用户名｜退出」；在游戏页（识别 `body[data-game-key]`）于 `.meta-chips` 后渲染收藏条：三个切换按钮 已有/想买/想玩，乐观更新，未登录点击引导跳登录并带 return URL
- **`account.html`（新增，「我的收藏」页）**：未登录显示登录/注册双 tab 表单；已登录显示三张清单（每项：游戏名链接 + BGG 权重/评分 chip（读 `window.BGG_RATINGS`，你选游戏最看重权重）+ 三状态互移按钮 + 移除）
- **`tools/wire-account.mjs`（新增）**：仿 wire-seti-sidebar.mjs 幂等正则注入 1652 个游戏页（`data-game-key` 属性 + account.js 引用）；同步改 `tools/build-bga.mjs` 模板，保证 BGA 页重生成不丢
- **`index.html`**：引入 account.js；**`assets/css/style.css`**：增补收藏条/account 页/topbar-auth 样式（沿用主题变量，移动端友好）

## 三、部署（deploy.yml + 服务器一次性引导）

- **deploy.yml**：静态 rsync 增加 `--exclude='server/'`；新增步骤：setup-go → `CGO_ENABLED=0 GOOS=linux GOARCH=amd64` 交叉编译 → scp 二进制到服务器 `/opt/rules-api/` → `systemctl restart rules-api` → curl 验证 `https://zhibinai.cn/api/health`
- **一次性引导**（实施时 SSH 上服务器）：查看现有 nginx 配置后在 zhibinai.cn server 块加 `location /api/ { proxy_pass http://127.0.0.1:8787; }`（`nginx -t` 通过后再 reload）；安装 systemd 单元（`Environment=DB_PATH=/opt/rules-api/data/rules.db`，仅监听 127.0.0.1）
